# Виджет банковских операций клиента
## Описание
### Данный проект содержит функции для обработки списка транзакций
main.py - Для запуска и теста всего проекта
masks.py - Для маскировки номеров карт и счетов при помощи звездочек
widget.py - Преобразует дату в более читаемый вид
processing.py - Фильтрует и сортирует данные операций по картам
decorators.py - Для декоратора log который делает доги ко всем функциям

## Тестирование
Проект протестирован. Содержит Pytest.
### Установка и проверка pytest через Poetry
poetry add --group dev pytest
Запустите тесты с помощью команды в терминале pytest.

## Установка и использование.
Все функции реализованы на Python и совместимы с версиями Python 3.6 и выше.

## Примеры использования.
Работу функций можно запустить и проверить через файл ./src/main.py
